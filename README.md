# 📚 Exam Management System

A web-based Exam Management System developed using PHP, HTML, CSS, and Bootstrap. This system is designed to simplify and automate the handling of student exams, results, and related administrative tasks.

---

## 🚀 Features

- Student registration and login
- Admin panel to manage exams, questions, and results
- Add, edit, delete exam questions
- Conduct online exams with timer
- Auto-grading for objective questions
- View student results and reports
- Responsive UI using Bootstrap

---

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, Bootstrap 4/5
- **Backend:** PHP (Core)
- **Database:** MySQL
- **Server:** Apache (XAMPP / WAMP recommended)
